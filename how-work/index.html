️ Основные компоненты

Проект состоит из нескольких ключевых компонентов, которые работают вместе для автоматизации публикации фотографий.

Telegram-бот

Основной инструмент администратора. Принимает фотографии, управляет базой данных, парсит информацию о транспорте и публикует посты в канал.

Python 3.14 Aiogram 3.x FSM
📦

GitHub репозиторий

Хранилище всех данных: фотографий, баз данных постов, транспортных средств и галерей. Работает как база данных через REST API.

GitHub API JSON Base64
🌐

Веб-сайт

Публичный интерфейс для просмотра фотографий. Загружает данные напрямую из GitHub репозитория и отображает их в удобном формате.

HTML5 CSS3 JavaScript
📡

Transphoto.org парсер

Автоматическое извлечение информации о транспортных средствах с сайта transphoto.org по ссылке.

BeautifulSoup Requests HTML Parsing

📝 Процесс добавления поста

Пошаговое описание того, как создаётся новая публикация.

1

Загрузка фотографии

Администратор отправляет фото боту. Бот сжимает изображение (до 1280px) и загружает в папку uploads/ репозитория через GitHub API.

2

Выбор галереи

Бот показывает список галерей из gallery.json. Можно выбрать существующую или создать новую.

3

Добавление транспортных средств

Ввод номера Т/С или ссылки на transphoto.org. Бот ищет в базе transport.json или парсит данные с сайта. Можно добавить до 40 Т/С на пост.

4

Указание маршрута

Ввод номера маршрута (например, "11" или "11, 5"). Применяется ко всем Т/С в посте.

5

Место съёмки (3 этапа)

Пошаговый ввод: Страна → Область/Регион → Город/Место. Данные сохраняются раздельно для гибкости.

6

Дата съёмки

Ввод в формате ДД.ММ.ГГГГ. Бот автоматически форматирует в "14 Июля 2024".

7

Публикация

Бот сохраняет пост в photos.json и отправляет фото с подписью в Telegram-канал. Подпись включает Т/С, маршрут, место и дату.

🗄️ Структура данных

Все данные хранятся в JSON-файлах в корне репозитория.

Файл Назначение Содержимое
photos.json База постов ID, путь к фото, галерея, Т/С, место, дата
transport.json База Т/С Модель, номер, депо, год, VIN, статус
gallery.json Категории ID и название галереи
uploads/*.jpg Фотографии Сжатые JPEG изображения
